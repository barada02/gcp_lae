# GCP Experimental Learning Project

This repository contains experimental projects and code samples for learning Google Cloud Platform (GCP) services and technologies.

## Purpose

This is a hands-on learning repository where I explore various GCP services, APIs, and best practices through practical implementations.

## Project Structure

- `storage_to_pubsub/` - Cloud Storage to Pub/Sub integration experiments
- `str_to_BigQuery/` - String data processing to BigQuery workflows

## Getting Started

Make sure you have the Google Cloud CLI installed and authenticated:

```bash
gcloud auth login
gcloud config set project YOUR_PROJECT_ID
```

## Note

This repository is for educational and experimental purposes. Code samples may not be production-ready and are intended for learning GCP concepts and services.
